Real-Time Sign Language Recognition System (PSL)
Developed a real-time recognition system for Pakistan Sign Language (PSL) using YOLOv8 and OpenCV, achieving an accuracy of ~95%. Personally collected and annotated a custom PSL dataset tailored to project requirements with sign variability and mouth movement (data cannot be shared due to privacy constraints). The system processes live webcam input, detects hand gestures, and displays bounding boxes and labels in real time. It also generates a live transcript of detected signs, enabling smooth interpretation for continuous sign language sequences.

Key Highlights:

- Built and trained a custom YOLOv8 model for PSL gesture recognition.

- Collected and annotated a personal PSL dataset for model training.

- Achieved ~95% recognition accuracy on custom test data.

- Implemented real-time recognition and transcription from webcam input.
